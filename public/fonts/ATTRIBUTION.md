# Self-hosted fonts

The Workbench theme's three typefaces, committed as woff2 (latin subset
only, only the weights the site uses). No remote font requests: the real
site loads nothing from Google Fonts or Fontshare.

- **Big Shoulders Display 800** — headings. Google Fonts (OFL 1.1),
  via `@fontsource/big-shoulders-display@5.2.5`
  (`files/big-shoulders-display-latin-800-normal.woff2`).
- **IBM Plex Sans 400 / 500** — body. Google Fonts / IBM (OFL 1.1),
  via `@fontsource/ibm-plex-sans@5.2.5`
  (`files/ibm-plex-sans-latin-400-normal.woff2`,
  `files/ibm-plex-sans-latin-500-normal.woff2`).
- **Departure Mono 400** — labels / UI / readouts. Helena Zhang
  (OFL 1.1), v1.500 release zip from
  `rektdeckard/departure-mono`
  (`DepartureMono-Regular.woff2`).

All three are under the SIL Open Font License 1.1 — full text in
`OFL.txt` in this directory.
