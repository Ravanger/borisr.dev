OpenParty is a TypeScript framework for multi-device party games: the game runs on a TV-connected PC while the host and players join from their phones.

It ships with four reference games, all built only on the framework's packages:

## How it works

One command launches a game:

```bash
bun run launch wit-clash
```

That opens the host page, and players join with a room code. Bots can fill empty seats and play by themselves, and games with a terminal entry can be played at a prompt or watched as an all-bot demo.

Under the hood the framework is split into small packages — the Colyseus-free runtime, the Colyseus host, a Svelte 5 client SDK, generic viewmodels and components, a bot kit, terminal clients, and a launcher that runs the server, code API, client, bots or demo as one process group. Tests enforce 100% coverage.
