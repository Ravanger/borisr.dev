A multi-screen desktop display built around an ESP32-C3 SuperMini and a 0.96-inch SSD1306 OLED. Four screens, stepped through with one push button: Clock (time synced over WiFi via NTP), Indoor (temperature and humidity from a DHT11 sensor), Outdoor weather, and a Summary screen with brightness, WiFi status and uptime. A potentiometer controls screen brightness; an optional rotary encoder can replace the button, and an optional PIR sensor blanks the display when the room is quiet.

Two firmwares run on the same hardware and wiring. ESPHome is the default: the gadget joins Home Assistant, indoor readings and uptime appear there, outdoor weather comes from a Home Assistant weather entity, and updates go over the air after the first USB flash. The standalone Arduino sketch is the backup: it fetches outdoor weather itself from Open-Meteo — free, no API key, no account — and needs no Home Assistant at all.
